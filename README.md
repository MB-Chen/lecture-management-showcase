## 📊 核心结论速记

- **自建 7 表**：`jygl_lecture_group`（申请组，流程绑定实体）+ `jygl_lecture_group_item`（选课号明细）+ `jygl_material_file`（两级上传文件）+ `jygl_hy_folder_map`（鸿翼目录映射，存 CreateFolder 快照，目录重建会失配）+ `jygl_hy_token_cache` + `jygl_hy_perm_config` + `jygl_approver_folder`（授权账本方案B）
- **审批链五节点**：课程负责人 → 教学秘书 → 教务处处长（只读）→ 教学院长（终点）→ 已通过；驳回回开始节点
- **提交粒度**：课程组 = 一条审批流，选课号 = 组内明细（逐条落库）；支持撤回(terminateProcess)/重提；**拆组(splitGroup)未实现**（第一版砍掉）
- **文件两级上传**：课程级共享（L4 课程/{教师工号}）+ 选课号级专属（L5 按需创建）
- **教务 10 表直连**：部门/学年/教师/课程/教学班/教师映射/行政班映射/负责人/课程替换/日志
- **课程负责人**：1:1（课程→负责人），数据源 `tpm_approval_set.task_user3`，100% 匹配教师表
- **四级权限**：教师(teacher_id) / 负责人(leader_id) / 学院(teaching_college) / 全校（教务处处长+校机关）
- **阶段路线**：核心闭环已跑通 → SSO 免登已落地 → 授权账本方案B（授课程L4）已闭环 → 撤回/重提/移除单人权限已实现；**H5 移动审批仅页面框架+表格数据源、逻辑未写**；余下见待办清单（H5 审批逻辑+钉钉消息、版本历史弹窗、拆组、生产参数配置）
